# Описание бизнес-процесса: Заказ еды в ресторане с доставкой

**Участники (роли):** Клиент, Ресторан (Оператор/Повар), Курьер, Система доставки.

**Шаги процесса:**
1. Клиент выбирает блюда в мобильном приложении и нажимает кнопку "Оформить заказ".
2. Система автоматически проверяет наличие выбранных блюд в ресторане и доступность свободных курьеров (Условие ветвления 1).
3. Если блюд нет в наличии, Система отправляет Клиенту уведомление об отказе, и процесс завершается.
4. Если блюда есть, заказ автоматически поступает на кухню Ресторана.
5. Повар начинает готовить заказ, и параллельно с этим Система назначает ближайшего свободного Курьера (Параллельное действие).
6. Курьер приезжает в ресторан и забирает упакованный готовый заказ.
7. Система проверяет выбранный Клиентом способ оплаты (Условие ветвления 2).
8. Если оплата была онлайн, Курьер просто вручает заказ Клиенту.
9. Если оплата наличными, Курьер принимает деньги, выдает чек и только затем вручает заказ.
10. Клиент получает еду, Система фиксирует успешное завершение заказа.
