# Sequence Diagram: Обмен сообщениями при заказе

```mermaid
sequenceDiagram
    participant C as Клиент
    participant S as Система доставки
    participant R as Ресторан (Повар)
    participant K as Курьер

    C->>S: Оформить заказ
    S->>S: Проверка наличия блюд и курьеров
    alt Блюда есть в наличии
        S->>R: Передать заказ на кухню
        S->>K: Назначить ближайшего курьера
        R->>K: Передать готовый заказ
        alt Оплата онлайн
            K->>C: Вручить заказ
        else Оплата наличными
            K->>C: Принять деньги и выдать чек
            K->>C: Вручить заказ
        end
        S->>S: Зафиксировать успешное завершение
    else Блюд нет в наличии
        S->>C: Уведомление об отказе
    end
